RecurIterator

Source: recur_iterator.js:26

An iterator for a single recurrence rule. This class usually doesn't have to be instanciated directly, the convenience method ICAL.Recur#iterator can be used.

Constructor

new RecurIterator(options: Object): RecurIterator

Creates a new ICAL.RecurIterator instance. The options object may contain additional members when resuming iteration from a previous run.

Parameters

  • options (Object) — The iterator options
    • options.rule (ICAL.Recur) — The rule to iterate.
    • options.dtstart (ICAL.Time) — The start date of the event.
    • options.initialized (Boolean, optional) — When true, assume that options are from a previously constructed iterator. Initialization will not be repeated.
